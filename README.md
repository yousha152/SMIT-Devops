Python Calculator

A simple and secure calculator built with Python, FastAPI, and Jinja2, featuring safe expression evaluation, calculation history, and JSON-based data storage.

Features:

Basic arithmetic operations
Addition, subtraction, multiplication, and division
Modulus, floor division, and exponentiation
Calculation history
JSON-based history storage
Current result display
Clear history option
Keyboard support
FastAPI backend
Jinja2 templates for the frontend
